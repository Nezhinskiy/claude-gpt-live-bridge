## Is it elegant? Is anything redundant?

**The investigation is.** It found that a warning which vanished from `validate` still holds, and
reaches further than the warning said, and it recorded what was not seen. The README change that
links the "the voice says so" bullet to the limit is the right, small move. The ADR item says each
fact once.

**The README entry is the weak spot:** one bullet of 14 lines, carrying the limit, what to do, three
settings, the administrator's way out and the evidence, in seven languages (S-1).

## Findings

Line numbers are at `b09f249`.

### Important

**P-1. The letter (p) is taken.** `docs/adr/0001-platform-findings.md:405` and `:458`.

- PR 38 merged "(p) The lowest Claude Code the mod loads on" into `dev`. This adds a second "(p)",
  so "ADR 0001 (p)" now names two findings. The PR body cites it that way twice. The letters exist
  so that later work can cite them (`:10`).
- **Resolution:** make this one (q), and bump "to (p)" at `:10`.

**P-2. The site still says it without exception.** `site/index.html:197`: "When Claude waits for a
permission prompt, the voice tells you, and you answer it in Claude Code".

- The PR changed that claim in all seven READMEs "because it claimed that without exception". The
  site says the same to more readers, and the diff does not touch it.
- **Resolution:** add the exception, linking to the README's known limitations.

**P-3. The overview's new sentence is false for one of the table's rows.**
`docs/architecture/overview.md:326`: "This notice is not sent where Claude Code's built-in guard
loads".

- Row 4 of the ADR's table has the guard loaded and the hooks running: "as with none, the guard
  loaded". It is the way out the README offers. As written, the architecture document says a
  deployed mod cannot send the notice.
- **Resolution:** "where the guard loads and the mod is not the organization's own".

**P-4. "Measured" covers more than was measured.** `README.md:420-421`, and the same sentence in all
six translations.

- "The cases with managed settings are measured" closes an entry saying "the voice says nothing
  about it and the menu bar shows Claude working". The ADR says a real voice line was not observed:
  that part comes from reading the code. It is a sound reading (below), but it is not a measurement.
- The hooks were measured on Linux, on a Mac app's README, which does not say so.
- The PR body lists both as "Not tested, and worded that way in the docs". That holds for the ADR,
  not for the README. The rule is that docs never claim more than was observed, and the sentence
  exists to say which is which.
- **Resolution:** for example: "The hooks were [measured](…) in a Linux container; what the voice
  and the menu do follows from the code, and no real line was run. The Team and Enterprise case and
  the marketplace copy come from Claude Code's documentation."

### Minor

**P-5. The link to the admin page has an anchor that does not exist.** All seven READMEs:
`#install-your-organizations-mods-and-set-the-order`. The page's heading has the id
`install-your-organizations-mods`, and its own contents list links to that, so the link lands at the
top of a long page. The ADR's `#know-what-happens-by-default` is right. **Resolution:** the short
anchor, in seven files.

**P-6. ADR 0001 (i) still says "Documented only".** `docs/adr/0001-platform-findings.md:395-403`
ends "Not observed: the CLI could not run a model turn here". The new item ran a real dialog and saw
those hooks, so (i) now understates what the ADR knows. **Resolution:** point (i) at the new item.

**P-7. Two statements go a little past their rows.**

- `README.md:413`, "Claude Code prints a line saying the hook was skipped": seen on 2.1.312 and
  2.1.318. The floor is 2.1.301. The admin page's note in `/plugin` starts at 2.1.299, so that half
  is safe.
- `CHANGELOG.md`'s four named hooks: `classic.PostToolUseFailure` was not observed in the table. The
  2.1.301 warning names it and the guard stops `classic.*`, so the claim is sound, but it is
  inferred.

Neither needs changing unless P-4's sentence is rewritten; both then fit under it.

**P-8. "Everything works" is the PR body's, and rests on the probe.** The table's third row ran a
probe mod, not this mod, and only on 2.1.312. The README says only "those hooks run", which is
right. Nothing tested the organization's own deployment together with `allowManagedHooksOnly` or
`allowManagedModsOnly`; the admin page says such a mod still runs under the second. The body is not
a document, so this matters only if it is copied.

**P-9. zh-CN lists the settings with ASCII commas.** `README.zh-CN.md:295`: ``
`allowManagedHooksOnly`, `allowManagedModsOnly` ``. Chinese text around it uses `、`. Cosmetic.

**S-1. The entry could be shorter.** `README.md:408-421`. Two bullets would read better: what
happens to the owner, then what an administrator can do. Most readers have no managed settings and
need only the first. The second could link to the ADR for the settings by name, which would keep
seven copies of three setting names out of the READMEs. A judgement call: the names are what an
administrator looks for.

**Which row was seen on which version.** The table's versions match the PR body. Rows 1 and 2 have
three versions, and the rest only 2.1.312. Row 3 had no dialog, so it does not show
`classic.PermissionRequest` running without the guard, and the ADR says so. The README states no
version, which is right for a limit that holds on all of them, and it does not imply more.

**`SECURITY.md` stays true.** It does. `SECURITY.md:27-29` says LiveBridge has no code that answers
a prompt, and that the hook "only tells the voice that a prompt is waiting". Where the hook does not
run it tells nothing, and the control is untouched: the dialog still appears, and only the owner
answers. The file claims nothing about the notice always arriving. No change is needed.

**The translations.** All six carry every clause of the English entry and of the changed bullet:
what goes silent, the guard and where it loads, the prompt and the menu bar, the printed line and
`/plugin`, the questions, the three settings, the administrator's way out, the marketplace copy, and
the evidence sentence. All six in-page anchors match their headings. They inherit P-4 and P-5, and
P-9 is the one difference. This is a reader's check, not a native speaker's.

**The ADR says the fact once.** It does: the guard's rule once, the versions in the table, and "not
observed" once. It adds no second home for the limit: the README and the overview link to it. The
fault in it is the letter (P-1).
