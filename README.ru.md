# claude-gpt-live-bridge

Разговаривайте голосом с открытой сессией Claude Code. Приложение в строке меню macOS,
**LiveBridge**, держит наготове голосовую линию GPT-Live через `codex app-server` на вашем входе
в ChatGPT (без API-ключа). Голос работает как ресепшен: болтает, уточняет, что вы имеете в виду,
и передаёт настоящую работу сессии Claude через небольшой мод Claude Code, `livebridge`. Claude
делает работу своей моделью, своими инструментами и в своём режиме разрешений, а голос сообщает
вам результат.

*English version: [README.md](README.md). Основной текст — английский; перевод может отставать.*

> **Неофициальный проект.** Он не связан с Anthropic или OpenAI, не одобрен и не поддерживается
> ими. Он опирается на экспериментальный realtime API codex, который может измениться с любым
> выпуском codex.

## Требования

- macOS 14 или новее на Apple Silicon.
- Claude Code 2.1.289 или новее (моды).
- [Codex CLI](https://github.com/openai/codex) (`codex`, проверено с 0.166.0), установленный через
  Homebrew или npm, в `PATH`, который ваша оболочка задаёт в окне Terminal, с входом через `codex
  login` в план ChatGPT, в который входит realtime-голос. LiveBridge не запускает codex, чей
  `codex features list` он не может прочитать, поэтому другая версия может не запуститься, пока
  LiveBridge не обновят.
- Для сборки приложения: Xcode со Swift 6.0 или новее. Проверенные версии перечислены в
  [CONTRIBUTING.md](CONTRIBUTING.md#toolchain). Собранное приложение работает на macOS 14 или
  новее.

## Установка

Мод — из маркетплейса этого репозитория:

```sh
claude plugin marketplace add Nezhinskiy/claude-gpt-live-bridge
claude plugin install livebridge@claude-gpt-live-bridge
```

Приложение — сборка из исходников с установкой в `~/Applications`:

```sh
git clone https://github.com/Nezhinskiy/claude-gpt-live-bridge.git
cd claude-gpt-live-bridge
scripts/build-app.sh --release
```

Чтобы обновиться, снова запустите `scripts/build-app.sh --release`. Сборка подписана ad hoc,
поэтому после каждого обновления macOS снова спрашивает доступ к микрофону. Чтобы разрешение
сохранялось, один раз запустите `scripts/build-app.sh --make-signing-identity`: скрипт сначала
спросит, затем создаст самоподписанный сертификат для подписи кода в вашей связке ключей
входа, и следующие release-сборки будут подписаны им.

При первом звонке macOS спросит доступ к микрофону и может спросить, можно ли LiveBridge
находить устройства в локальной сети. Голосовой линии нужно и это второе разрешение; без него
звонок остановится с фразой, где его включить.

Чтобы удалить всё, что хранит приложение: `scripts/build-app.sh --uninstall`. Скрипт удаляет
приложение, его объект входа и его файлы и печатает две команды, которые оставляет вам:
`tccutil reset Microphone io.github.nezhinskiy.livebridge` и `claude plugin uninstall
livebridge@claude-gpt-live-bridge`.

## Использование

В сессии Claude Code, с которой хотите говорить:

| Команда | Что делает |
|---|---|
| `/live on` | Подключает сессию к LiveBridge под её заголовком и открывает приложение, если оно не запущено. |
| `/live off` | Отключает сессию от LiveBridge. |
| `/live target` | Делает эту сессию той, которой голос передаёт работу. |
| `/live status` (или просто `/live`) | Одна строка: звонок, цель, непрослушанные результаты, минуты за сегодня. |
| `/live context` | Отправляет голосу краткую сводку сессии, которую пишет модель самой сессии. |
| `/live context auto` / `manual` | Отправляет эту сводку каждый раз, когда сессия становится целью, или только по запросу. |

Команда называется `/live`, а не `/voice`, потому что `/voice` — собственный голосовой режим
Claude Code.

Затем нажмите **Start** — в полосе над полем ввода или во всплывающем окне в строке меню — и
говорите. Во всплывающем окне Start недоступна, пока не подключилась хотя бы одна сессия.
Всплывающее окно показывает подключённые сессии (щелчок по сессии делает её целью), последние
реплики разговора и строку контекста ровно в том виде, в каком она была отправлена; в нём есть
**New conversation**, **Open at login** (по умолчанию выключено) и минуты, которые голосовая
линия была открыта сегодня.

Что делает голос:

- Сам отвечает на светскую беседу и объяснения и передаёт всё, чему нужны репозиторий или
  сессия: задачи, вопросы о коде, решения, исправления и остановки.
- Прежде чем передать что-то разрушительное или внешнее (удалить, запушить, опубликовать,
  отправить, задеплоить, оплатить), повторяет запрос и спрашивает «да?». Это привычка, которую
  голосу велено соблюдать, а не защита; что защищает, сказано в [SECURITY.md](SECURITY.md).
- Пересказывает результаты одной-двумя фразами с названием сессии. Блоки кода и таблицы
  остаются в сессии, а распознанные учётные данные скрываются.
- Когда Claude задаёт вопрос, голос задаёт его вам и отправляет ваш ответ обратно в ту же
  сессию. Работа, которую Claude заканчивает позже в фоне, приходит как обновление.
- Когда Claude ждёт ответа на запрос разрешения, голос говорит об этом. На запрос вы отвечаете
  в Claude Code; LiveBridge никогда не отвечает за вас.

## Бережно к оплате

Realtime-сессия голоса стоит денег, пока открыта, поэтому LiveBridge открывает её, только пока
кто-то говорит:

- Пока звонок включён и никто не говорит, микрофон питает только детектор голоса на вашем Mac.
  Никуда ничего не отправляется.
- Когда вы начинаете говорить, линия открывается. Две секунды до начала речи сохраняются и
  отправляются первыми, так что первые слова не теряются.
- Линия закрывается после 20 секунд тишины или сразу после того, как голос подтвердил передачу
  задачи. Звук без слов (музыка, телевизор) закрывает её через 90 секунд.
- Результат, пришедший при закрытой линии, звучит сигналом и ждёт: полоса и всплывающее окно
  показывают его как непрослушанный, и голос расскажет о нём, когда вы заговорите снова.
  Результат считается услышанным, только когда голос произнёс его в ответе
  ([правило](docs/architecture/overview.md#a-result-while-the-line-is-closed)); если линия
  закрылась раньше, он снова звучит сигналом и ждёт.
- У каждой сессии Claude Code свой разговор с голосом. Он переносится в следующую
  realtime-сессию, а также через Stop и Start, поэтому голос помнит, что вы сказали минуту назад.
  Новая цель переключает разговор: открытая линия закрывается, и ваши следующие слова открывают
  её с разговором новой цели.
- Всплывающее окно показывает минуты открытой линии по замеру приложения; как ваш план
  тарифицирует realtime-голос, не публикуется.

## Приватность

У LiveBridge нет телеметрии, и он не слушает ни одного сетевого порта; мод общается с
приложением через Unix-сокет в папке, которую может открыть только ваш пользователь. Что уходит
в OpenAI через realtime-сессию codex:

- звук микрофона, пока линия открыта: от двух секунд до начала вашей речи до закрытия линии;
- инструкции голоса;
- недавний разговор сессии-цели (до 24 последних реплик), чтобы продолжить его в новой
  realtime-сессии;
- запросы сессии-цели, которые ещё не закрыты, в виде их однострочных описаний;
- каждый результат, вопрос, обновление и уведомление о разрешении — одной строкой не длиннее
  2000 символов, без блоков кода и таблиц. Обновление — это ответ Claude в следующем ходе,
  начатом уведомлением фоновой задачи, в течение 10 минут после голосового запроса и пока в
  сессии не начался любой другой ход;
- сводка контекста сессии, когда вы её загружаете, — одной строкой не длиннее 1500 символов.
  Всплывающее окно показывает эту строку ровно в том виде, в каком она была отправлена;
- с каждой строкой выше — метка её сессии: название сессии Claude Code или, если его нет, имя
  папки сессии;
- WebRTC-предложение, в котором локальные сетевые адреса Mac указаны как кандидаты для
  соединения.

Результаты, вопросы, обновления и сводки сначала проходят через фильтр, который скрывает
известные виды учётных данных (закрытые ключи, JWT, распространённые API-токены, пароли в URL,
поля вроде `password=`). Это список шаблонов, а не гарантия.

Тред codex, который несёт голос, эфемерный и только для чтения; в нём выключены все функции
codex, кроме хранения входа и работы через прокси, и все MCP-серверы; он нужен только для
разговора. Работа Claude уходит в Anthropic, как и всегда в вашей сессии Claude Code. На вашем
Mac приложение хранит счётчик минут, а также для каждой из 20 последних использованных сессий
её недавний разговор и последнюю загруженную из неё строку контекста, пока вы не нажмёте
**New conversation**, когда она цель, или не уберёте её, в
`~/Library/Application Support/claude-gpt-live-bridge`.

В [SECURITY.md](SECURITY.md) — модель угроз; коротко: всё, что слышит ваш микрофон, может стать
запросом, который Claude выполнит в режиме разрешений самой сессии.

## Известные ограничения

- Когда ваши следующие слова снова открывают линию, голос иногда отвечает только на них и не
  произносит ждущий результат. Результат не теряется: он продолжает ждать, звучит сигналом, когда
  линия закрывается, и снова передаётся голосу, когда линия откроется в следующий раз.
- В сессии Claude Code, которая была открыта ещё до загрузки мода, `/live` может заработать
  только после того, как сессию откроют заново.
- Произнёс ли ответ ждущий результат, определяется по его словам и списку частых слов только
  английского и русского языков. На другом языке результат может засчитаться услышанным, когда
  голос лишь упомянул его.
