LiveBridge — приложение в строке меню macOS, которое держит наготове голосовую линию GPT-Live
через `codex app-server` на вашем входе в ChatGPT (без API-ключа). Голос работает как ресепшен:
болтает, уточняет, что вы имеете в виду, и передаёт настоящую работу вашей сессии Claude Code
через небольшой мод Claude Code, `livebridge`. Claude делает работу своей моделью, своими
инструментами и в своём режиме разрешений, а голос сообщает вам результат.

*Основной текст — английский ([README.md](README.md)); перевод может отставать.*

<p align="center"><img src="site/assets/demo.gif" alt="Разговор с сессией Claude Code через LiveBridge" width="100%"></p>

**Всё локально.** Никакой телеметрии и никакого своего сервера: LiveBridge — мост на вашем Mac
между вашим собственным codex и вашим собственным Claude Code. Приложение и мод общаются через
Unix-сокет, доступный только вашему пользователю, и приложение не слушает ни одного сетевого
порта. Ваш Mac покидает только то, что эти два инструмента и так отправляют: голосовая линия в
OpenAI через ваш codex, и только пока она открыта, и работа Claude в Anthropic через вашу сессию
Claude Code. Что именно уходит в OpenAI, перечислено в разделе [«Приватность»](#приватность); от
чего это защищает, а от чего нет, — в [SECURITY.md](SECURITY.md).

> **Неофициальный проект.** Не связан с Anthropic или OpenAI, не одобрен и не поддерживается
> ими. Опирается на экспериментальный realtime API codex, который может измениться с любым
> выпуском codex.

## Быстрый старт

Нужны macOS 14+ на Apple Silicon, Claude Code 2.1.289+ и
[codex](https://github.com/openai/codex) с входом (`codex login`) в план ChatGPT с
realtime-голосом; чтобы собрать приложение самому, ещё Xcode со Swift 6.0+. Подробности — в
разделе [«Требования»](#требования).

```sh
# 1. Мод — из маркетплейса этого репозитория
claude plugin marketplace add getLiveBridge/livebridge
claude plugin install livebridge@livebridge

# 2. Приложение — сборка из исходников, установка в /Applications и запуск
git clone https://github.com/getLiveBridge/livebridge.git
cd livebridge
scripts/build-app.sh --release
```

3. В сессии Claude Code, с которой хотите говорить, наберите `/live on`.
4. Нажмите **Start** в полосе над полем ввода, разрешите доступ к микрофону и говорите.

Не хотите собирать? В каждом [выпуске](https://github.com/getLiveBridge/livebridge/releases/latest)
есть приложение образом диска, который собирает и заверяет GitHub Actions; как его проверить и
открыть, сказано в разделе [«Из образа диска»](#из-образа-диска). Мод ставится одинаково в обоих
случаях.

Если в сессии, открытой ещё до установки, команды `/live` нет, откройте сессию заново
([почему](#известные-ограничения)). Обновление, разрешения, сохранение доступа к микрофону между
обновлениями и удаление описаны в разделе [«Установка»](#установка).

## Требования

- macOS 14 или новее на Apple Silicon.
- Claude Code 2.1.289 или новее (моды).
- [Codex CLI](https://github.com/openai/codex) (`codex`, проверено с 0.166.0), установленный через
  Homebrew (`brew install --cask codex`) или npm (`npm install -g @openai/codex`), в `PATH`,
  который ваша оболочка задаёт в окне Terminal, с входом через `codex login` в план ChatGPT, в
  который входит realtime-голос. LiveBridge не запускает codex, чей `codex features list` он не
  может прочитать, поэтому другая версия может не запуститься, пока LiveBridge не обновят.
- Для сборки приложения: Xcode со Swift 6.0 или новее. Проверенные версии перечислены в
  [CONTRIBUTING.md](CONTRIBUTING.md#toolchain). Собранное приложение работает на macOS 14 или
  новее.

## Установка

Мод ставится из маркетплейса этого репозитория (команды из [«Быстрого старта»](#быстрый-старт)).
Приложение в обоих случаях оказывается в `/Applications`: из образа диска или собранное из
исходников. И так и так оно подписано ad hoc и не нотаризовано.

### Из образа диска

1. Скачайте
   [LiveBridge.dmg](https://github.com/getLiveBridge/livebridge/releases/latest/download/LiveBridge.dmg)
   из последнего выпуска.
2. Проверьте его с помощью [GitHub CLI](https://cli.github.com) в папке, куда сохранили файл:

   ```sh
   gh attestation verify LiveBridge.dmg --repo getLiveBridge/livebridge
   ```

   Проверка проходит, только если образ собран из тега выпуска
   [рабочим процессом выпуска](.github/workflows/release.yml) этого репозитория. Это
   единственное доказательство происхождения образа: подпись ad hoc никого не называет.
3. Откройте образ и перетащите LiveBridge в Applications.
4. При первом запуске macOS блокирует приложение, пока вы не разрешите запуск в System
   Settings > Privacy & Security > **Open Anyway**.

Чтобы обновиться, замените приложение на приложение из нового выпуска. После каждого
обновления macOS снова спрашивает доступ к микрофону.

### Из исходников

`scripts/build-app.sh --release` собирает приложение, устанавливает его в `/Applications` (у
вашей учётной записи должно быть право записи туда, как у администратора) и запускает. Чтобы
обновиться, запустите команду снова. Сборка подписана ad hoc, поэтому после каждого обновления
macOS снова спрашивает доступ к микрофону. Чтобы разрешение сохранялось, один раз запустите
`scripts/build-app.sh --make-signing-identity`: скрипт сначала спросит, затем создаст
самоподписанный сертификат для подписи кода в вашей связке ключей входа, и следующие
release-сборки будут подписаны им.

### Разрешения

Первый Start спрашивает у macOS доступ к микрофону. Если доступ запрещён, звонок
останавливается с фразой, а кнопка **Open Microphone Settings** в меню LiveBridge в строке меню
открывает «Конфиденциальность и безопасность» > «Микрофон», где нужно разрешить LiveBridge. С
подписью ad hoc macOS спрашивает снова после каждого обновления (см. выше). macOS может также
спросить, можно ли LiveBridge находить устройства в локальной сети. Голосовой линии нужно и это
второе разрешение; без него звонок остановится с фразой, где его включить.

### Удаление

Из клона репозитория `scripts/build-app.sh --uninstall` удаляет `/Applications/LiveBridge.app`,
как бы оно ни было установлено, его объект входа и все файлы, которые оно хранит, и печатает две
команды, которые оставляет вам: `tccutil reset Microphone com.getlivebridge.livebridge` и
`claude plugin uninstall livebridge@livebridge`.

Без клона выключите **Open at login** в Settings приложения LiveBridge, закройте LiveBridge и
выполните те же шаги в Terminal:

```sh
rm -rf /Applications/LiveBridge.app ~/Library/Application\ Support/LiveBridge \
  ~/Library/{Caches,WebKit}/com.getlivebridge.livebridge \
  ~/Library/HTTPStorages/com.getlivebridge.livebridge{,.binarycookies} \
  ~/Library/Preferences/com.getlivebridge.livebridge.plist
tccutil reset Microphone com.getlivebridge.livebridge
claude plugin uninstall livebridge@livebridge
```

## Использование

### Команды

В сессии Claude Code, с которой хотите говорить:

| Команда | Что делает |
|---|---|
| `/live on` | Подключает сессию к LiveBridge под её заголовком и открывает приложение, если оно не запущено. |
| `/live off` | Отключает сессию от LiveBridge. |
| `/live target` | Делает эту сессию той, которой голос передаёт работу. |
| `/live status` (или просто `/live`) | Одна строка: звонок, цель, непрослушанные результаты, минуты за сегодня. |
| `/live context` | Отправляет голосу новую краткую сводку сессии, которую пишет модель самой сессии. |

Команда называется `/live`, а не `/voice`, потому что `/voice` — собственный голосовой режим
Claude Code. Отправлять ли сводку сессии каждый раз, когда она становится целью, решает не
команда, а одна настройка для всех сессий в окне [Settings](#настройки) приложения LiveBridge.

### Полоса и меню

Нажмите **Start** — в полосе над полем ввода или в меню LiveBridge в строке меню — и говорите.

- **Start в полосе** делает её сессию целью, начинает звонок и отправляет голосу сводку сессии
  ([подробности](docs/architecture/overview.md#components)). Пока звонок идёт с другой сессией,
  полоса показывает **Talk here**.
- **Меню в строке меню** показывает звонок, подключённые сессии (щелчок делает сессию целью),
  **Load context**, **Conversation** — разговор цели в том виде, в каком его хранит LiveBridge,
  минуты, **Settings…** и **Quit LiveBridge**.
- **New conversation…** стирает разговор цели и её загруженный контекст, а × у сессии убирает её
  и стирает её разговор; оба пункта сначала спрашивают. Голос начинает заново со следующего
  открытия линии, а `/live on` в убранной сессии снова её подключает.

### Настройки

**Settings…** открывает окно настроек LiveBridge:

- **Voice**: один из голосов realtime, которые предлагает ваш codex (codex перечисляет их, когда
  окно открывается), или **Codex default**. Звучит со следующего открытия линии.
- **Prompt** (по умолчанию пусто): ваши собственные указания голосу, например «Speak with me in
  Spanish», до 2 000 символов. Они добавляются после собственных правил LiveBridge для голоса,
  которые важнее, если они расходятся, и действуют со следующего открытия линии.
- **Load a session's context automatically when it becomes the target** (по умолчанию выключено):
  одна настройка для всех сессий, её хранит приложение.
- **Notify when a result is waiting** (по умолчанию включено): вместе с сигналом о результате,
  который ждёт, пока линия закрыта, уведомление macOS называет сессию («Alpha has a new result —
  speak to hear it»), но никогда не сам результат. Щелчок по нему открывает меню LiveBridge.
- **Open at login** (по умолчанию выключено).

### Что делает голос

- Сам отвечает на светскую беседу и объяснения и передаёт всё, чему нужны репозиторий или
  сессия: задачи, вопросы о коде, решения, исправления и остановки.
- Прежде чем передать что-то разрушительное или внешнее (удалить, запушить, опубликовать,
  отправить, задеплоить, оплатить), повторяет запрос и спрашивает «да?». Это привычка, которую
  голосу велено соблюдать, а не защита; что защищает, сказано в [SECURITY.md](SECURITY.md).
- Пересказывает результаты одной-двумя фразами с названием сессии. Блоки кода и таблицы
  остаются в сессии, а распознанные учётные данные скрываются.
- Когда Claude задаёт вопрос, голос задаёт его вам и отправляет ваш ответ обратно в ту же
  сессию. Работа, которую Claude заканчивает позже в фоне, приходит как обновление.
- Когда Claude ждёт ответа на запрос разрешения, голос говорит об этом. На запрос вы отвечаете
  в Claude Code; LiveBridge никогда не отвечает за вас.

## Бережно к оплате

Realtime-сессия голоса стоит денег, пока открыта, поэтому LiveBridge открывает её, только пока
кто-то говорит или пока может прийти ответ Claude на ваш только что переданный запрос:

- Пока звонок включён и никто не говорит, микрофон питает только детектор голоса на вашем Mac.
  Никуда ничего не отправляется.
- Когда вы начинаете говорить, линия открывается. Две секунды до начала речи сохраняются и
  отправляются первыми, так что первые слова не теряются.
- Линия закрывается после 20 секунд тишины. Звук без слов (музыка, телевизор) закрывает её
  через 90 секунд.
- Когда голос передаёт запрос Claude (handoff), линия остаётся открытой до 2 минут после этой
  передачи и оплачивается как любая открытая линия, а голос произносит ответ Claude, как только
  никто не говорит. Следующая передача начинает эти 2 минуты заново; разговор, который ничего не
  отправляет Claude, закрывается после обычных 20 секунд тишины.
- Результат, пришедший позже, при закрытой линии, звучит сигналом и ждёт: полоса и меню
  показывают его как непрослушанный, и голос расскажет о нём, когда вы заговорите снова
  ([когда он считается услышанным](docs/architecture/overview.md#a-result-while-the-line-is-closed)).
- У каждой сессии Claude Code свой разговор с голосом. Он переносится в следующую
  realtime-сессию, а также через Stop и Start, поэтому голос помнит, что вы сказали минуту назад.
  Новая цель переключает разговор: открытая линия закрывается, и ваши следующие слова открывают
  её с разговором новой цели.
- Меню показывает минуты открытой линии по замеру приложения; как ваш план
  тарифицирует realtime-голос, не публикуется.

## Приватность

У LiveBridge нет телеметрии, и он не слушает ни одного сетевого порта; мод общается с
приложением через Unix-сокет в папке, которую может открыть только ваш пользователь. Что уходит
в OpenAI через realtime-сессию codex:

- звук микрофона, пока линия открыта: от двух секунд до начала вашей речи до закрытия линии;
- инструкции голоса: собственные правила LiveBridge, а затем ваш **Prompt** из Settings, если
  вы его написали;
- недавний разговор сессии-цели (до 24 последних реплик), чтобы продолжить его в новой
  realtime-сессии;
- запросы сессии-цели, которые ещё не закрыты, в виде их однострочных описаний;
- каждый результат, вопрос, обновление и уведомление о разрешении — одной строкой не длиннее
  2000 символов, без блоков кода и таблиц. Обновление — это ответ Claude в следующем ходе,
  начатом уведомлением фоновой задачи, в течение 10 минут после голосового запроса и пока в
  сессии не начался любой другой ход;
- сводка контекста сессии-цели — одной строкой не длиннее 1500 символов. Она сохраняется при
  загрузке и отправляется при каждом открытии линии, пока эта сессия — цель, в том числе после
  Stop и Start и перезапуска приложения. Подменю Conversation показывает эту строку ровно в том
  виде, в каком она отправляется;
- с каждой строкой выше — метка её сессии: название сессии Claude Code или, если его нет, имя
  папки сессии;
- WebRTC-предложение, в котором локальные сетевые адреса Mac указаны как кандидаты для
  соединения.

Результаты, вопросы, обновления и сводки сначала проходят через фильтр, который скрывает
известные виды учётных данных (закрытые ключи, JWT, распространённые API-токены, пароли в URL,
поля вроде `password=`). Это список шаблонов, а не гарантия.

Тред codex, который несёт голос, эфемерный и только для чтения; в нём выключены все функции
codex, кроме хранения входа и работы через прокси, и все MCP-серверы; он нужен только для
разговора. Работа Claude уходит в Anthropic, как и всегда в вашей сессии Claude Code.

На вашем Mac приложение хранит свои настройки, счётчик минут, а также для каждой из 20 последних
использованных сессий её недавний разговор и последнюю загруженную из неё строку контекста, в
`~/Library/Application Support/LiveBridge`. Реплики сессии стираются, когда вы нажимаете **New
conversation**, пока она цель, или убираете её через ×. Отключившаяся сессия хранит их, пока их
не вытеснят 20 сессий, использованных позже; чтобы стереть их раньше, снова наберите в ней
`/live on` и нажмите **New conversation**. Удаление приложения стирает всё.

В [SECURITY.md](SECURITY.md) — модель угроз; коротко: всё, что слышит ваш микрофон, может стать
запросом, который Claude выполнит в режиме разрешений самой сессии.

## Известные ограничения

- Результат, пришедший, пока линия его ждёт, передаётся голосу как текст, который нужно
  произнести; у codex нет вызова, который заставил бы голос заговорить сразу, поэтому когда
  сказать, решает модель. В проверке голос произнёс его через несколько секунд. Если нет,
  результат остаётся непрослушанным: голос скажет его после ваших следующих слов, или он
  прозвучит сигналом, когда линия закроется.
- Когда ваши следующие слова снова открывают линию, голос иногда отвечает только на них и не
  произносит ждущий результат. Результат не теряется: он продолжает ждать, звучит сигналом и
  приходит уведомлением, когда линия закрывается, и снова передаётся голосу, когда линия
  откроется в следующий раз.
- В сессии Claude Code, которая была открыта ещё до загрузки мода, `/live` может заработать
  только после того, как сессию откроют заново.
- В приложении Claude для компьютера `/live`, набранная в сессии, процесс Claude Code которой ещё
  не запущен (новая сессия или только что открытая заново), может показать «/live isn't a command
  here.» Команда всё равно выполняется. Приложение берёт список команд такой сессии из проверки,
  которую запускает с выключенными хуками, поэтому код мода, объявляющий `/live`, там не
  работает; когда сессия запущена, приложение берёт список у неё самой. Со стороны мода это не
  исправить: статический файл команды попал бы в список как `/livebridge:live`, а не `/live`, и
  с выключенными хуками отправил бы свой текст модели вместо того, чтобы запустить мод.
- Произнёс ли ответ ждущий результат, определяется по его словам и списку частых слов только
  английского и русского языков
  ([правило](docs/architecture/overview.md#a-result-while-the-line-is-closed)). На другом языке
  результат может засчитаться услышанным, когда голос лишь упомянул его.

## Планы и где нужна помощь

Сегодня LiveBridge — это одно приложение для Mac, один исполнитель (Claude Code) и один
поставщик голоса (codex на входе в ChatGPT). Три части стыкуются через узкие швы, и каждое из
направлений ниже открыто для участников. Задачи по ним помечены меткой
[help wanted](https://github.com/getLiveBridge/livebridge/issues?q=is%3Aissue+is%3Aopen+label%3A%22help+wanted%22);
с каких файлов начать, сказано в [CONTRIBUTING.md](CONTRIBUTING.md#where-to-start).

- **Windows и Linux.** Приложение в строке меню, его аудиостраница и сервер сокета привязаны к
  macOS; протокол между модом и приложением и сам мод переносимы. Перенос начинается с
  приложения для новой платформы, которое говорит по тому же протоколу.
- **Другие агенты-исполнители**, например Codex CLI, Hermes Agent или Gemini CLI: каждому нужен
  свой адаптер, который говорит по тому же протоколу, что и мод Claude Code.
- **Другие поставщики голоса**, например OpenAI Realtime API с вашим собственным API-ключом или
  Gemini Live API от Google: каждый стал бы ещё одной реализацией realtime-протокола приложения.
